# Aryan Thakur — Portfolio

Personal portfolio site, structured after [adeolaadeoti/adeolaadeoti-v2](https://github.com/adeolaadeoti/adeolaadeoti-v2)
(MIT licensed) as a design/architecture reference — rebuilt from scratch with original content,
copy, and a distinct color scheme.

## Stack

- [Next.js](https://nextjs.org/) (Pages Router) + TypeScript
- SCSS for styling
- [Framer Motion](https://www.framer.com/motion/) for animation
- [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll) for smooth scrolling (desktop)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Editing content

- **Projects** — [data/projects.ts](data/projects.ts)
- **Hero copy / bio / links** — [pages/index.tsx](pages/index.tsx)
- **Colors / spacing** — [styles/_variables.scss](styles/_variables.scss)

## Deploying

Deploys cleanly to [Vercel](https://vercel.com/) — connect the repo and it auto-detects Next.js.
